04.04 / Project Pulse Widget

RepoPulse

RepoPulse is a project-level update widget for showing recent movement directly on individual Workshop pages.

It came from wanting each project page to feel alive without writing manual status updates every time I make progress. RepoPulse uses recent Git commits as the source for small project updates, like a pulse check for what changed most recently.

Purpose

The goal is not to judge productivity by commit count. The goal is to turn project-level Git activity into a small update widget so visitors can see what changed, when it changed, and whether the project is still moving.

Current Status

Planned Prototype

The first version will read recent commits for a specific project and turn them into short update entries that can live on that project's page.

Page Widget

RepoPulse is meant to be a lightweight, dynamic page element, not a heavy dashboard or productivity scoreboard.

Visual Signal

The widget should pop visually: a small shiny status element that makes recent project movement easy to notice.

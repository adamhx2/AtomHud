04.05 / Email Constructor

Relay

Relay is an early-stage idea for constructing reusable emails from smaller, dependable content blocks.

It is meant to reduce the repeated work of rebuilding similar messages while keeping the final email editable and specific to the situation.

Purpose

The goal is to explore a lightweight way to assemble recurring email structures without turning them into rigid templates or hiding the writing behind a complicated system.

Current Status

Concept Stage

Relay has not been built yet. The current work is defining the smallest useful version and the workflow it should support.

Reusable Blocks

The core idea is to combine saved openings, explanations, requests, and closings into a useful first draft.

Editable Output

Generated messages should remain easy to revise so the tool supports writing instead of replacing it.

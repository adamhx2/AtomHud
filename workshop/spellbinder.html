04.03 / Technical Memory Tool

Spellbinder

Spellbinder is a desktop-first snippet vault for reusable working blocks: code snippets, functions, spreadsheet formulas, SQL queries, commands, and useful text.

It sits somewhere between a clipboard manager and a personal snippet library. It came from the friction that builds up during real work: useful blocks I keep rewriting, formulas I reuse, queries I want to adapt, and context that is easy to lose once I move to the next task.

Purpose

The goal is not to become a giant knowledge system. The goal is to make reusable technical content easier to save, find, edit, and use again without digging through old files, chats, or scattered notes.

Current Status

Active Prototype

I am using Spellbinder to explore how much structure a personal workflow tool needs before it starts getting in the way.

Reusable Blocks

The project focuses on code snippets, helper functions, Excel/Sheets formulas, SQL snippets, commands, and reusable text blocks.

Search and Tags

Sorting, searching, and tagging are planned so the tool becomes a real quality-of-life upgrade instead of another place to lose notes.

Snippet Sanitizing

A planned sanitizing layer will clean user-added content so snippets can be edited or displayed without breaking the surrounding structure.
